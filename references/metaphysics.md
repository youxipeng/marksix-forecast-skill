## 1. 天干地支 / 五行 time field

Use the target Hong Kong draw time. With `lunar_python`, derive exact year, month, day and hour Gan-Zhi. Convert stems and branches to their standard five elements.

Project lottery translation:

- Determine a time-element emphasis from day stem and hour stem.
- Map each 1–49 number to a 河图 element by its last digit.
- Give the largest bonus when the number element matches the day/hour field, a smaller bonus when it is generated by that field, neutral-to-small when it generates the field, and a penalty for a controlling relation.

The time-to-number translation is a project convention, not a claim from a classical text.

## 2. 河图洛书

河图 number-to-element mapping used here:

- 1/6 → 水
- 2/7 → 火
- 3/8 → 木
- 4/9 → 金
- 5/10 → 土

For 1–49, use the last digit, with 0 treated as 10/土.

洛书 palace layout:

`4 9 2 / 3 5 7 / 8 1 6`.

Project lottery translation maps `n` to palace `((n-1) mod 9)+1`. This cycling is an explicit modeling convention for extending nine palaces to 49 lottery numbers.

Score components may include target-date digital-root palace, main/secondary palace relations, and the palace field supplied by the 奇门 sub-engine.

## 3. 梅花易数 time hexagram

Use the traditional time-number convention:

- year and hour use Earthly-Branch ordinals 子=1 … 亥=12;
- month/day use lunar month/day numbers;
- upper trigram = `(year_branch + lunar_month + lunar_day) mod 8`;
- lower trigram = `(same + hour_branch) mod 8`;
- moving line = `(same + hour_branch) mod 6`;
- zero remainder maps to 8 for trigrams and 6 for the moving line;
- innate trigram numbers: 乾1 兑2 离3 震4 巽5 坎6 艮7 坤8.

Construct main, mutual and changed hexagrams; determine body/use from the moving line and five-element relations.

Project lottery translation rewards numbers whose mod-8 class matches the main trigrams, whose mod-6 class matches the moving line, and whose 河图 element matches the body/use elements. Keep these contributions visible separately.

## 4. 奇门遁甲 event-time palace feature

This skill uses a deliberately narrow, auditable subset of 时家转盘奇门 for lottery feature engineering:

1. determine the target solar term and Yin/Yang Dun;
2. determine upper/middle/lower 5-day segment within the current solar-term interval;
3. use the standard 24-solar-term × three-yuan Ju table to obtain the Ju number;
4. lay the Earth Plate `戊己庚辛壬癸丁丙乙` forward for Yang Dun and backward for Yin Dun from the Ju palace;
5. map each lottery number to a Lo-Shu palace via `((n-1) mod 9)+1`;
6. score the palace using Three-Wonders (`乙丙丁`) emphasis plus five-element relation to the target day/hour field and a small Ju-palace bonus.

This is **not** presented as a full classical奇门断局. Full rotating Heaven/Star/Gate/Spirit plates have many school-specific boundary conventions. The subset is used because it is deterministic, testable, and sufficient to create an independent palace feature without pretending unresolved traditions are settled facts.

## Ensemble rule

Normalize each available metaphysics engine to 0–100, then average them equally. If `lunar_python` is unavailable, do not synthesize lunar/干支/梅花/奇门 results; report the missing engines and use only available features.

The final answer must show component scores so the user can later test whether any metaphysics engine adds out-of-sample value or only noise.
